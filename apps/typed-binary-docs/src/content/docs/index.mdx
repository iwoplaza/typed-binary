## Schemas are the types

Define the shape of your data once. Typed Binary infers what each schema reads and writes, and catches mismatches
before anything is encoded. Hover over the code below to see what TypeScript sees.

```ts twoslash title="player.ts"
// @errors: 2322
import * as bin from 'typed-binary';

const Vec3f = bin.tuple([bin.f32, bin.f32, bin.f32]);

const Player = bin.struct({
  name: bin.string,
  health: bin.u8,
  position: Vec3f,
});

type Player = bin.ExtractOut<typeof Player>;
//   ^?

const buffer = new ArrayBuffer(64);

Player.write(bin.cursor(buffer), {
  name: 'Ada',
  health: 100,
  position: [1, 2],
});

const player = Player.read(bin.cursor(buffer));
//    ^?
```
